# Identidade visual — RMBarros-Dev

## Conceito

Identidade minimalista e executiva para o perfil profissional e o portfólio de desenvolvimento de software. O sistema visual utiliza o monograma RM, composição geométrica e contraste entre verde profundo, marfim e cobre.

A identidade deve transmitir rigor técnico, clareza, consistência e evolução contínua, sem recorrer a elementos visuais excessivamente decorativos.

## Paleta oficial

| Token | HEX | Aplicação |
|---|---|---|
| Verde profundo | `#0B1F16` | Fundo principal e identidade institucional |
| Verde secundário | `#102D21` | Gradientes, superfícies e profundidade |
| Marfim | `#F5F2E8` | Texto, áreas claras e contraste |
| Cobre | `#B8733A` | Destaques, linhas e assinatura |
| Grafite | `#1A1A1A` | Texto e superfícies neutras |

## Ativos oficiais

- `assets/brand/logo.svg`: monograma vetorial RM.
- `assets/brand/banner.svg`: banner horizontal principal do perfil.
- `assets/brand/logo-light.svg`: versão alternativa para fundos escuros ou aplicações que exijam a variação clara.

## Tipografia e composição

- Priorizar tipografia serifada no monograma e nos elementos de assinatura.
- Utilizar fontes sans-serif para informações técnicas e textos de interface.
- Preservar alinhamento, proporções, área de respiro e legibilidade.
- Manter o banner em composição horizontal e evitar cortes que comprometam o monograma ou a assinatura.

## Aplicação no GitHub

- Utilizar os ativos locais do repositório em vez de recriar o símbolo em cada README.
- Manter os READMEs em português e inglês visualmente equivalentes.
- Utilizar badges de forma moderada, com cores compatíveis com a paleta.
- Evitar cartões de estatísticas fornecidos por serviços externos quando não forem necessários para compreender o portfólio.
- Escrever textos alternativos descritivos para imagens e símbolos.
- Não utilizar a identidade para sugerir certificações, vínculos institucionais ou experiências que não estejam comprovados.

## Manutenção

Ao alterar a identidade, atualizar este documento e verificar os arquivos SVG, os dois READMEs e as referências visuais. Não modificar cores, proporções ou elementos do monograma isoladamente sem revisar a consistência do conjunto.
