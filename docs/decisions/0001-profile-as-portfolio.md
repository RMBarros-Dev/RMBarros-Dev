# ADR-0001 — Manter o repositório principal como portfólio

- **Status:** Registrado (decisão atual, documentada retrospectivamente)
- **Data do registro:** 2026-11-15

## Contexto

Uso o repositório `RMBarros-Dev` como ponto de entrada para apresentar minha formação, meus projetos, as tecnologias que exploro e a documentação relacionada.

## Decisão atual

Mantenho este repositório como uma página de portfólio e documentação, enquanto mantenho o código de cada aplicação em seu próprio repositório. Utilizo assets locais da identidade visual e uma validação automatizada para conferir SVGs e referências essenciais.

## Consequências

- Posso apresentar os projetos sem misturar seus ciclos de desenvolvimento.
- A qualidade da apresentação depende de links e informações atualizados nos repositórios de origem.
- A validação do perfil verifica estrutura e referências locais; não substitui revisão editorial nem testes dos aplicativos.
- Registro alterações relevantes neste diretório.

## Nota histórica

Documentei a estrutura atual de forma retrospectiva. Não atribuo esta justificativa a uma decisão histórica específica que não esteja registrada.
