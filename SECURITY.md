# Política de segurança

## Escopo

Mantenho este repositório como portfólio público. Considero relevantes, entre outros, problemas que exponham credenciais, dados pessoais, conteúdo privado, arquivos maliciosos ou links que comprometam a segurança dos visitantes.

## Como reporto ou recebo relatos

Peço que não sejam publicados detalhes de vulnerabilidades em Issues públicas. Quando o recurso estiver disponível, utilizo a opção **Report a vulnerability** na aba Security do GitHub para comunicação privada. Como alternativa, mantenho o contato por e-mail: cienciadacomputacaorenan@gmail.com.

## Versões suportadas

Prioritizo correções na branch padrão `main`. Não declaro suporte de segurança para versões antigas sem uma release correspondente.

## Tratamento

Analiso cada relato, procuro reproduzir o problema e documento a correção quando ela estiver concluída. Não estabeleço prazo de resposta ou de correção que eu não possa garantir.
