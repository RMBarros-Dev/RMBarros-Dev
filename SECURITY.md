# Política de segurança

## Escopo

Este repositório é um portfólio público. Problemas relevantes incluem exposição de credenciais, dados pessoais, conteúdo privado, arquivos maliciosos ou referências que coloquem visitantes em risco.

## Comunicação

Não publique detalhes de vulnerabilidades em Issues públicas. Utilize **Report a vulnerability** na aba Security do GitHub quando disponível. Alternativamente, entre em contato pelo e-mail cienciadacomputacaorenan@gmail.com.

## Tratamento

Os relatos serão avaliados e, quando possível, reproduzidos e corrigidos. Não é estabelecido prazo de resposta ou correção. A branch padrão priorizada é `main`; não há declaração de suporte para versões antigas sem release correspondente.
